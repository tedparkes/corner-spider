Corner Spider is a free Windows desktop companion: a jumping spider that
explores, hunts occasional prey, rests in a silk retreat and sometimes accepts
a finger ride. It uses local procedural artwork and saves; the pet itself does
not call an AI service.

## Built through iteration with AI assistance

This project grew from an unverified prototype through repeated human feedback,
code changes, Windows builds, visual review and testing. The creator supplied
direction and references, judged the results and requested refinements. AI
assistance was used to implement, debug, test and package those changes.

The revisions included repeated anatomy and foreleg corrections, more deliberate
movement, a redesigned finger interaction, planned upward departures, visible
retreat entry, species proportions, longer pounces and Portia's web-plucking
encounter. Even the web needed several passes: size, resident placement, patrol
avoidance, departure fading, edge attachments and finally a concave outer curve.

The complete development changelog is included below. The attached
`DEVELOPMENT-HISTORY.md` explains the feedback behind the milestones. Both
documents are also included in the ZIPs. Git history begins at RC3, so this
release includes the earlier work as well.

## Download and verification

Use the Windows ZIP for the runnable app, or the Source ZIP to build it yourself.
The packages include `docs/VERIFICATION.md`, which separates automated checks,
prior-build results and remaining manual testing. The release also includes
SHA-256 checksums. The application is unsigned.

Future ideas such as custom color regions, additional foods and a background
with depth are recorded in `ROADMAP.md`; they are not included features.
