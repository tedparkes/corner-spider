# Future ideas

These are future directions, not promised dates.

- Custom skins: color pickers for named body regions and saved local presets.
- More detailed species-specific courtship, web construction and prey wrapping,
  building on the life cycle and food variety introduced in 1.1.
- An optional background with depth: perches, surfaces, occlusion and spatial
  movement, while retaining the transparent desktop mode and a performance budget.
- Release polish: broader hands-on mixed-DPI/suspend coverage, accessibility
  review, long resource soaks and optional code signing.

The 1.1 preview implements the earlier food/species ideas: seven foods, five
categories, real and fictional varieties, living silk, molts and bounded broods.
See CHANGELOG.md and README.md for the implemented scope and its adaptations.
